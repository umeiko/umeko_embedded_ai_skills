# 剪辑决策、增量修改与检查

## 建议工程目录

```text
project/
  script.md                  # 分镜、旁白、画面需求
  project.json               # 唯一生效的时间线
  voice-request.json         # 分段 TTS 文本与参数，不含地址/凭证
  assets/                    # 用户授权的声音、图片
  raw/                       # 原始录屏，保留不覆盖
  footage/                   # 可直接剪的录屏
  voice/                     # 分段 WAV + 缓存清单
  output/v1/                 # 可重建产物
  output/v2/                 # 修改版，保留 v1
```

所有新增素材记录来源和用途。公开仓库只放脚本和模板，通常不放用户录屏、账号状态、商业素材或用户临时 TTS URL。

## 旁白先实测，画面后定长

长段配音容易在服务的最大生成长度处中止。按自然语义分成短段，给句尾留余量；若输出接近 `max_sec`，必须试听，必要时分段重配。`max_sec` 不是剪辑时间槽，也不能保证模型已经说完。

TTS 客户端接受用户提供的 Mambo 兼容接口：POST JSON，返回 WAV。可用参数如 `text_lang`、`speed_factor`、`top_k`、`top_p`、`temperature`、`max_sec`。不冒充任何服务内置在 agent 中。服务规格变更时调整薄适配层，不向未知地址发送文本。

音频略长可以 `atempo` 温和压缩；差距大时改文案或镜头。模板默认最多 1.2 倍，可按用户要求调整。输入素材会被检查，超出时不会静默裁掉旁白。旁白 `duration` 指它可占用的槽位，较短的旁白在后面补静音。

## 混音

1. 先处理旁白：切除手动录音开头无用的空白（先分析/试听，别猜起点），适度高通、响度整理。
2. 加 BGM。20%、35% 都是线性振幅系数，不同歌曲的母带响度不同，要听实际混音。重要旁白下方需要更安静时拆音乐片段或使用其他工具做 ducking。
3. 加角色短声、点击声和包袱处的原声，避免不必要的连续噪声。
4. 让 BGM 转场/结尾淡入淡出；检查接缝、突然中断和相位问题。
5. 最后限制峰值。过度触发限制器会让音乐泵动，应该降低轨道增益，不是继续加压缩。

脚本的旁白响度整理是 FFmpeg 单遍 `loudnorm`，混音峰值保护是 `alimiter`。这不等于严格的广播响度认证。若有明确 LUFS/TP 交付标准，增加两遍测量及成片复测。

## 字幕

使用画幅对应的 ASS 分辨率，字体要在实际渲染机上存在；缺字体会导致中文方框或回退字体。优先明确配置本机可用的中文字体。烧录前查看代表帧，字幕不压按钮、人脸和平台水印。不同平台的安全区可调整 `MarginV`。

SRT 保存文本，ASS 保存样式。大标题可另行通过画面素材或扩展 ASS 样式制作，附带脚本以简洁可读字幕为主。不要过早把所有字烧死在原始镜头上。

## 增量改片

- 保留原始录屏、未烧字幕的 `picture.mp4` 和干净旁白分轨。
- 改 BGM 增益时，从分轨重新混，不把旧混音再次乘系数。`remix` 使用 `-c:v copy`，减少等待和重复编码损失。
- 改片尾时，找明确切点并删除该点之后的旧字幕/音轨，再加入新片尾。任何跨越切点的事件都要检查，不只是删除 start 大于切点的行。
- 缓存必须依赖素材内容、输入位置、时长、滤镜、画幅和工具版本；源文件同名但内容改变也应失效。
- 语音文件存在不代表正确：TTS 请求内容、参数或服务变化需要新的缓存签名。

## 交付检查

- 片长、画幅、帧率、编码和音轨与任务约定一致。
- 开头无黑屏，尾部无残留旧字幕；随机抽取几个转场。
- 字幕没有缺字/溢出，配音句尾完整，BGM 没有盖住关键对白。
- 纯声音修订可比较 `ffmpeg -map 0:v:0 -c copy -f hash -hash sha256 -` 的前后视频流哈希，证明画面没重编码。
- 用户需要源包时，包含时间线、分镜、字幕、分轨和有权交付的素材；解压检查文件能找到，不把发布包成功等同于已上传平台。

## 常见故障

| 现象 | 处理 |
| --- | --- |
| TTS 返回 HTML/JSON 而非 WAV | 不按 `.wav` 保存为成功；报告 HTTP 状态/返回类型，检查用户提供的服务 |
| TTS 401/403/404 | 停止，等待用户修复地址/权限；先做独立画面工作 |
| 429、5xx、网络超时 | 有上限地退避；已成功段落保留，避免全片重配 |
| Windows ASS 滤镜报路径错误 | 渲染 cwd 切到输出目录，用相对 `ass=subtitles.ass`，不要把盘符直接塞进滤镜 |
| 声音越叠越小 | 检查 amix 默认归一化；使用 normalize=0 后主动设定增益与峰值保护 |
| 改音量后画质变差 | 从上一版视频流复制，仅替换音轨 |
| 快速玩法很卡 | 检查原始帧间隔/丢帧；提高输出 fps 不能补回未录到的动作 |
| 画面短于旁白 | 调整镜头或文案；不要裁断语句假装对齐 |

FFmpeg 官方参考：[concat demuxer](https://ffmpeg.org/ffmpeg-formats.html#concat-1)、[amix](https://ffmpeg.org/ffmpeg-filters.html#amix)、[loudnorm](https://ffmpeg.org/ffmpeg-filters.html#loudnorm)、[atempo](https://ffmpeg.org/ffmpeg-filters.html#atempo)、[alimiter](https://ffmpeg.org/ffmpeg-filters.html#alimiter)、[ass](https://ffmpeg.org/ffmpeg-filters.html#ass)。
